# Rohlfing Family Maps

Interactive map of where Eileen, Lorna, Lisa, Chantal and Carrie Rohlfing's ancestors were born, married and died.

**View it:** https://garydarling-cell.github.io/rohlfing-family-maps/

Built from the family's Reunion tree (export of 11 Nov 2026). The map shows what the tree currently says; some entries come from online trees and have not been checked against records.
